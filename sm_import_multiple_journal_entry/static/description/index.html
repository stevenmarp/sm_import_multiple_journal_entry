Step-by-Step Feature Flow

Visual walkthrough of importing multiple journal entries.
STEP 01

Prepare Your Data File

Format your Excel or CSV file. Rows sharing a matching Reference are grouped into a single journal entry. Accounts are matched by Code.

STEP 02

Open the Import Menu

Navigate to the Accounting module and click Import Multiple Journal Entries under the transaction actions dropdown.

STEP 03

Select File & Upload

Choose the target journal, upload your template file, configure headers/posting option, and click the Import button.

STEP 04

View Imported Entries List

After a successful import, Odoo redirects you to the list of newly created journal entries grouped by their respective references.

STEP 05

Validate Reference Matches

Open any imported journal entry to verify that the source file's Reference column correctly maps to the Odoo Journal Entry's Reference field.

STEP 06

Balanced Debit and Credit Lines

Every single line in the journal entry matches its respective account, debit, and credit values as specified in the import source.
